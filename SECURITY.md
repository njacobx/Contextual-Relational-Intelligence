# Security

Contextual Relational Intelligence™ is in active development, and no release has shipped yet. The code arrives with CRI 1.0.

## Reporting a vulnerability

Please report security issues privately, never in a public issue or discussion. Use GitHub's private vulnerability reporting: open the **Security** tab and choose **Report a vulnerability**, or go straight to
[report a vulnerability](https://github.com/njacobx/Contextual-Relational-Intelligence/security/advisories/new).

We'll acknowledge your report, keep you updated while we look into it, and credit you in the advisory if you'd like.

## Supported versions

None yet. From CRI 1.0, this page will list the versions that receive security fixes.
